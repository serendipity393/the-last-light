# 最后一盏灯

**解压后双击「最后一盏灯.exe」开始。请保留 data 文件夹。**

Windows 10/11 64 位，键盘鼠标，需要支持 OpenGL 3.3 的显卡。无需安装游戏引擎或开发工具，游戏无需联网。

你是一名回到故乡的灯塔维修员。用能照见过去的旧灯，穿过暴雨中的海港，找回妹妹留下的声音。

| 操作 | 按键 |
|---|---|
| 移动 | WASD |
| 灯光朝向 | 鼠标 |
| 看见回声 | 按住鼠标右键 |
| 交互 | 靠近后按 E |
| 推进对白 | E、空格或左键；首次补全文字，再次继续 |
| 安静慢行 | Shift |
| 声音诱饵 | Q，投向鼠标方向 |
| 提示 | H |
| 手记 | J |
| 暂停 / 退出机关 | Esc |
| 全屏 | F11 |

## 游玩提示

- 第一站是码头无线电，靠近后出现 E 提示。
- 回声灯的能量会自动恢复。耗尽后松开右键，等待冷却。
- 开灯会更容易吸引失声者；借建筑遮挡、慢行或投掷诱饵绕开它们。
- 被抓后回到检查点，已完成机关与收集物保留。
- H 的提示不会扣分，也不影响结局。解谜界面会暂停敌人行动。
- 六件可选记忆藏在各章角落，要用回声灯看见。不是通关必需品。

## 保存与分享

机关完成、记忆收集和章节切换自动保存。暂停菜单还可以保存当前位置。

存档位于游戏旁的 `存档` 文件夹，运行缓存位于 `运行数据`。请完整解压到你有写入权限的目录。

发送完整分享 ZIP 给朋友即可；不要只发送 EXE。你的个人存档不包含在官方分享 ZIP 中。如果自行重新打包，请排除 `存档` 与 `运行数据`。

## 内容说明

本作是四章完整的独立短篇，含六段记忆和两个结局。以程序化微缩模型呈现雨港，没有完整语音。首次探索原定目标为 30–45 分钟，尚未经真人盲玩计时；熟悉路线或频繁使用提示会更快。

结束后可以立即体验另一种告别，也可以通过已解锁章节补全记忆。新旅程会清空本轮收集和进度，但保留章节解锁。

若运行缓慢，在设置中将画质切换为「流畅」。游戏未进行数字签名，也未经过商店审核。
